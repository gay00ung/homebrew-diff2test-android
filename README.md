## Install

Direct install:

```bash
brew install gay00ung/diff2test-android/d2t
```

Or tap first:

```bash
brew tap gay00ung/diff2test-android
brew install d2t
```

## Formula

- `Formula/d2t.rb`

This formula installs the `d2t` CLI from the release ZIP published in the source repository.
