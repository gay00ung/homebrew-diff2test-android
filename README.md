# homebrew-diff2test-android

Homebrew tap for `d2t`, a diff-driven Android ViewModel test generation CLI.

## Install

Direct install:

```bash
brew install gay00ung/diff2test-android/d2t
```

Or tap first:

```bash
brew tap gay00ung/diff2test-android
brew install d2t
```

## Formula

- `Formula/d2t.rb`

The formula installs the `d2t` CLI from the release ZIP published in:

- [gay00ung/diff2test-android](https://github.com/gay00ung/diff2test-android)
